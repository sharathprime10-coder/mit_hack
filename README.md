# Team Anveshan - CPRI Data Challenge

This repository contains the complete modelling workflow used for the CPRI
test-record challenge. It classifies records as valid or invalid and predicts
the reference parameter for every test record.

## Repository contents

| File | Purpose |
| --- | --- |
| `pipeline.py` | Loads data, trains models, predicts, explains, and exports results |
| `training_data.csv` | Engineer-labelled historical records |
| `test_data.csv` | Unlabelled records for inference |
| `Anveshan.csv` | Submission file generated by the pipeline |
| `summary.json` | Counts, ranges, attention IDs, risk IDs, and feature importance |
| `methodology_note.md` | Modelling assumptions and rationale |
| `ARCHITECTURE.md` | System design and processing diagrams |
| `requirements.txt` | Python dependencies |

## Run the workflow

PowerShell:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python pipeline.py
```

The script reads the two CSV files beside `pipeline.py` and writes
`Anveshan.csv` and `summary.json` to the same directory. It can also be
run from another location:

```powershell
python C:\path\to\mit_hack\pipeline.py --data-dir C:\path\to\mit_hack
```

## Processing design

1. Validate the input schema and labels.
2. Select features using the valid training records.
3. Impute missing values using training medians only.
4. Preserve missingness indicators for validity classification.
5. Train a balanced XGBoost classifier.
6. Train Gaussian Process and XGBoost regressors on valid records only.
7. Rank attention by prediction uncertainty and report high-value thermal-risk IDs separately.
8. Export the required submission and an audit summary.

The current run produced 350 predictions, with 327 records classified as
valid and 23 as invalid. The validation and output details are recorded in
`summary.json`.
